🔍 Understanding "Data Leakage" in Your Context
For your project, "data leakage" primarily means that information from your test set has inadvertently influenced the training process. This can make your validation and test scores look artificially good and would mean your model wouldn't perform as well on truly new, unseen data. The main risks for your CNN on MNIST/Fashion-MNIST are:

Train/Test Contamination: The most common form. It happens when the exact same image data exists in both your training and test sets.

Target Leakage: When some feature in your data indirectly provides information about the target label. This is less common in image data where the pixels are the features, but it's a good general principle to check.

Augmentation Leakage: This is a subtle one. If your data augmentation (like random rotations) is applied after splitting your data, but you accidentally fit the augmentation parameters (like mean/std for normalization) on the entire dataset including the test set, that's a form of leakage.

🛡️ Practical Checks for a Clean Pipeline
Here are the steps you can implement in your code to verify there's no data leakage.

1. Verify the Train-Test Split (Checking for Contamination)
The most straightforward check is to ensure there is no overlap between your training and test sets. For image data, you can compare the unique pixel values or, more reliably, use a hash of the image array.

Add this check right after you load and preprocess your data:

python
import hashlib
import numpy as np

def check_train_test_overlap(x_train, x_test, verbose=True):
    """Checks for any exact image duplicates between train and test sets."""
    train_hashes = {hashlib.md5(img.tobytes()).hexdigest() for img in x_train}
    test_hashes = {hashlib.md5(img.tobytes()).hexdigest() for img in x_test}
    
    overlap = train_hashes.intersection(test_hashes)
    if overlap:
        print(f"❌ CRITICAL: Found {len(overlap)} duplicate images between train and test sets!")
        # You can optionally inspect the first few overlapping images
        return False
    else:
        if verbose:
            print("✅ Train-test split check passed: No exact image duplicates found.")
        return True

def check_augmentation_leakage(train_dataset, val_dataset):
    """Ensure validation transforms don't contain random augmentations."""
    val_transform = val_dataset.transform
    # Check for common random transforms. Add to this list if needed.
    random_transforms = ['RandomRotation', 'RandomAffine', 'RandomHorizontalFlip', 'RandomCrop']
    
    for t in random_transforms:
        if hasattr(val_transform, t) or any(t in str(trans) for trans in val_transform.transforms):
            print(f"❌ LEAKAGE DETECTED: Validation set uses {t}!")
            return False
    
    print("✅ Augmentation check passed: Validation transforms look deterministic.")
    return True
